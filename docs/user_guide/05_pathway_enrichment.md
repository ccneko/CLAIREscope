# Pathway Enrichment Studio (ORA)

## Hypergeometric Over-Representation Analysis
- Test upregulated or custom gene sets against curated MSigDB, Gene Ontology (BP, MF, CC), Reactome, and KEGG pathway libraries.
- Calculates hypergeometric fold enrichment, Fisher's exact p-values, and Benjamini-Hochberg FDR q-values.
- Generates interactive horizontal bar plots and structured enrichment summary tables.
