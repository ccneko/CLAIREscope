# Differential Expression & Volcano Plot Studio

## Pairwise & Group-Level Comparisons
- Compare target cohorts (e.g. condition A vs. condition B, or cluster X vs. cluster Y).
- Interactive Volcano Plot: Hover over points to view gene symbols, $\log_2\text{FC}$, and $-\log_{10}(p\text{-adj})$.
